This is the app's real cockpit running in your browser on data captured 21 Nov 2026. Switch between AAPL, MSFT, NVDA, JPM and TSLA from the name; the full app (a Python server) covers any US-listed company.

Filing changes

Compares each 10-K's Risk Factors and MD&A with the year before: new, dropped and reworded paragraphs, with a word-level redline. The change score is plain text similarity, so anyone can reproduce it, and Claude only explains paragraphs the comparison found. Research (Cohen, Malloy and Nguyen, "Lazy Prices", 2020) found that companies whose annual reports change a lot go on to underperform.

Track record

Every debate verdict, insider cluster and filing change becomes a dated call, graded against the S&P 500 at 30, 90 and 180 days, live and on history back to 2006. Calls are dated when the information became public, every number carries a 95% interval that resamples whole months, and small groups say "too few to judge".

Bull vs Bear

Two Claude agents argue for and against a stock using only its latest 10-K and 10-Q, tagging every claim with its source. A judge scores which side the filings support better and lists claims they don't.

Insider radar

Reads SEC Form 4 filings and flags companies where several insiders bought their own stock on the open market in the same few weeks. Grants, option exercises and pre-scheduled 10b5-1 trades are left out.

Mule ring detector

Turns transfers into a graph, scores every account with a GraphSAGE network and groups flagged accounts into the rings that move money between each other. On the synthetic set it recovers all 8 planted rings.

Which markets

FinSight reads the US SEC's filings, so it covers companies that file with the SEC: 10-Ks for filing changes and debates, Form 4s for insider buying. Indian (SEBI, NSE/BSE) and Japanese (EDINET, TDnet) disclosures use different systems and aren't supported yet. The mule ring detector works on any market's transfer data.

Run it

Needs Python 3.11 or newer, a Claude API key for debates and explanations, and a name and email for the SEC's User-Agent rule.

git clone https://github.com/riyadadlani02/finsight.git && cd finsight
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # set ANTHROPIC_API_KEY and SEC_USER_AGENT
streamlit run app.py
